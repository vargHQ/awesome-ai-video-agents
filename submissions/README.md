# Submissions

Drop `submissions/<slug>.md` here from [TEMPLATE.md](TEMPLATE.md) and open a pull request. `bun run check` validates it. A maintainer publishes the card to the catalog; the file is removed when the card is live and the card appears in `skills/` at the next sync. Faster route without git: connect `https://mcp.varg.ai/mcp` and tell your agent "publish this skill to varg how to". See [CONTRIBUTING.md](../CONTRIBUTING.md).
