# How to make AI images with GPT Image 2 in Claude Code

Two agent skills and a CLI for GPT Image 2/2.5: generate and edit images, and pull the prompt out of a reference image.

## Install

```bash
# Claude Code
/plugin marketplace add wuyoscar/gpt_image_2_skill, then /plugin install gpt-image@wuyoscar-skills
```
