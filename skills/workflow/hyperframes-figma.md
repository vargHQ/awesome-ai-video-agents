Turn a Figma link into video: rendered assets, brand tokens, components and storyboard frames rebuilt as motion.

## Install

```bash
# Claude Code
claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

# Codex
npx skills add heygen-com/hyperframes --skill figma -a codex

# Cursor
npx skills add heygen-com/hyperframes --skill figma -a cursor

# Gemini CLI
npx skills add heygen-com/hyperframes --skill figma -a gemini-cli
```
