## Install

```bash
# Claude Code
/plugin marketplace add higgsfield-ai/skills
/plugin install higgsfield@higgsfield

# Codex
npx skills add higgsfield-ai/skills --skill higgsfield-product-photoshoot -a codex

# Cursor
npx skills add higgsfield-ai/skills --skill higgsfield-product-photoshoot -a cursor

# Gemini CLI
npx skills add higgsfield-ai/skills --skill higgsfield-product-photoshoot -a gemini-cli
```
