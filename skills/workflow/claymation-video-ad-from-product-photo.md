# Turn a Product Photo into a Claymation Video Ad

Vertical 10-11 scene claymation ad from a product photo and an angle: GPT Image 2 keyframes, Gemini Omni Flash clips, ElevenLabs voice on fal.ai, ~$6-8.

## Install

```bash
# Claude Code
Download claymation-ads.zip, then in the Claude desktop app go to Customize → Skills → Add → Upload a skill and upload it.
```

## Run it on varg

Generation (images, video, voice, music, lip-sync, captions, render) runs with one account on [varg.ai](https://varg.ai): the `varg-ai` skill (`npx skills add vargHQ/skills --skill varg-ai`) or the MCP server `https://mcp.varg.ai/mcp`. Quote the cost first with `estimate_cost`. 1 credit = $0.01, free plan, no card.
