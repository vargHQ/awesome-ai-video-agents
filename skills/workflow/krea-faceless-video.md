## Install

```bash
# Claude Code
/plugin marketplace add krea-ai/skills
/plugin install krea@krea

# Codex
npx skills add krea-ai/skills --skill faceless-video -a codex

# Cursor
npx skills add krea-ai/skills --skill faceless-video -a cursor

# Gemini CLI
npx skills add krea-ai/skills --skill faceless-video -a gemini-cli
```
