- **Tags:** `faceless` `narration` `animation` `subtitles`
- **Full card, kept current:** <https://varg.ai/how-to/skills/higgsfield-video-explainer.md>

## Install

```bash
# Claude Code
/plugin marketplace add higgsfield-ai/skills
/plugin install higgsfield@higgsfield

# Codex
npx skills add higgsfield-ai/skills --skill higgsfield-video-explainer -a codex

# Cursor
npx skills add higgsfield-ai/skills --skill higgsfield-video-explainer -a cursor

# Gemini CLI
npx skills add higgsfield-ai/skills --skill higgsfield-video-explainer -a gemini-cli
```
