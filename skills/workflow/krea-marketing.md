## Install

```bash
# Claude Code
/plugin marketplace add krea-ai/skills
/plugin install krea@krea

# Codex
npx skills add krea-ai/skills --skill krea-marketing -a codex

# Cursor
npx skills add krea-ai/skills --skill krea-marketing -a cursor

# Gemini CLI
npx skills add krea-ai/skills --skill krea-marketing -a gemini-cli
```
