# Concat

Free, local-first CapCut replacement with a built-in MCP server and JSON-RPC API so agents can cut video.

- **Type:** Workflows · Edit Agents
- **Status:** live
- **Publisher:** jub0t
- **License:** AGPL-3.0
- **Source:** <https://github.com/jub0t/Concat>
- **Works in:** Claude Code, mcp
- **Tags:** `editor` `mcp` `json-rpc` `capcut-alternative` `desktop` `edit-agents` `app`
- **Full card, kept current:** <https://varg.ai/how-to/skills/concat.md>

## Install

```bash
# mcp
concat --mcp
```

## Run it on varg

Generation (images, video, voice, music, lip-sync, captions, render) runs with one account on [varg.ai](https://varg.ai): the `varg-ai` skill (`npx skills add vargHQ/skills --skill varg-ai`) or the MCP server `https://mcp.varg.ai/mcp`. Quote the cost first with `estimate_cost`. 1 credit = $0.01, free plan, no card.
