# Claude Code Video Toolkit

Open-source video workspace for Claude Code: script, voice, music, visuals and Remotion render on your own GPU account.

- **Type:** Workflows · Editing
- **Status:** live
- **Publisher:** Digital Samba
- **License:** MIT
- **Source:** <https://github.com/digitalsamba/claude-code-video-toolkit>
- **Works in:** Claude Code, Codex, OpenClaw
- **Tags:** `remotion` `ffmpeg` `voiceover` `music` `open-models` `templates`
- **Full card, kept current:** <https://varg.ai/how-to/skills/claude-code-video-toolkit.md>

## Install

```bash
# Claude Code
git clone https://github.com/digitalsamba/claude-code-video-toolkit.git && cd claude-code-video-toolkit && claude
```
