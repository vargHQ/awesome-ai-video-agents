# PixiJS

Build fast 2D WebGL/WebGPU graphics with PixiJS v8; routes each task to the right PixiJS skill.

- **Type:** Guides · Tooling
- **Status:** live
- **Publisher:** PixiJS
- **License:** MIT
- **Source:** <https://github.com/pixijs/pixijs-skills/tree/main/skills/pixijs>
- **Works in:** Claude Code, Codex, Cursor, Gemini CLI
- **Tags:** `webgl` `webgpu` `2d` `canvas` `shaders`
- **Full card, kept current:** <https://varg.ai/how-to/skills/pixijs.md>

## Install

```bash
# Claude Code
npx skills add https://github.com/pixijs/pixijs-skills --skill pixijs -a claude-code

# Codex
npx skills add https://github.com/pixijs/pixijs-skills --skill pixijs -a codex

# Cursor
npx skills add https://github.com/pixijs/pixijs-skills --skill pixijs -a cursor

# Gemini CLI
npx skills add https://github.com/pixijs/pixijs-skills --skill pixijs -a gemini-cli
```
