# PixiJS Custom Rendering

Write custom shaders, uniforms and batchers for PixiJS v8 that run on both WebGL and WebGPU.

- **Type:** Guides · Shaders
- **Status:** live
- **Publisher:** PixiJS
- **License:** MIT
- **Source:** <https://github.com/pixijs/pixijs-skills/tree/main/skills/pixijs-custom-rendering>
- **Works in:** Claude Code, Codex, Cursor, Gemini CLI
- **Tags:** `glsl` `wgsl` `uniforms` `webgpu`
- **Full card, kept current:** <https://varg.ai/how-to/skills/pixijs-custom-rendering.md>
