# HyperFrames

Turn HTML, CSS and seekable animation into deterministic MP4s: launch films, explainers, captions, title cards.

- **Type:** Guides · Explainers
- **Status:** live
- **Publisher:** HeyGen
- **License:** Apache-2.0
- **Source:** <https://github.com/heygen-com/hyperframes/tree/main/skills/hyperframes>
- **Works in:** Claude Code, Codex, Cursor, Gemini CLI
- **Tags:** `brand-motion` `kinetic-type` `captions` `html-to-video` `gsap` `motion-graphics`
- **Full card, kept current:** <https://varg.ai/how-to/skills/hyperframes.md>

## Install

```bash
# Claude Code
claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

# Codex
npx skills add heygen-com/hyperframes --skill hyperframes -a codex

# Cursor
npx skills add heygen-com/hyperframes --skill hyperframes -a cursor

# Gemini CLI
npx skills add heygen-com/hyperframes --skill hyperframes -a gemini-cli
```
