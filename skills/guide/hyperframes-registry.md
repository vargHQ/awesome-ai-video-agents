# HyperFrames Registry

Pull any of ~450 ready-made blocks into a video as editable source: transitions, titles, captions, charts, 3D.

- **Type:** Guides · Tooling
- **Status:** live
- **Publisher:** HeyGen
- **License:** Apache-2.0
- **Source:** <https://github.com/heygen-com/hyperframes/tree/main/skills/hyperframes-registry>
- **Works in:** Claude Code, Codex, Cursor, Gemini CLI
- **Tags:** `shaders` `kinetic-type` `captions` `transitions` `components` `hyperframes`
- **Full card, kept current:** <https://varg.ai/how-to/skills/hyperframes-registry.md>

## Install

```bash
# Claude Code
claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

# Codex
npx skills add heygen-com/hyperframes --skill hyperframes-registry -a codex

# Cursor
npx skills add heygen-com/hyperframes --skill hyperframes-registry -a cursor

# Gemini CLI
npx skills add heygen-com/hyperframes --skill hyperframes-registry -a gemini-cli
```
