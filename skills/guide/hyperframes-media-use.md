## Install

```bash
# Claude Code
claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

# Codex
npx skills add heygen-com/hyperframes --skill media-use -a codex

# Cursor
npx skills add heygen-com/hyperframes --skill media-use -a cursor

# Gemini CLI
npx skills add heygen-com/hyperframes --skill media-use -a gemini-cli
```
