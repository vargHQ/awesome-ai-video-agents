## Install

```bash
# Claude Code
/plugin marketplace add EL4CTEO/blender-skills
/plugin install blender-agent-skills@blender-agent-skills

# Codex
git clone https://github.com/EL4CTEO/blender-skills && ./blender-skills/install/install.sh --agent codex

# Cursor
git clone https://github.com/EL4CTEO/blender-skills && ./blender-skills/install/install.sh --agent cursor

# Gemini CLI
git clone https://github.com/EL4CTEO/blender-skills && ./blender-skills/install/install.sh --agent gemini
```
