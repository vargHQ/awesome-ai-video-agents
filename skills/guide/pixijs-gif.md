- **Type:** Guides · Image
- **Status:** live
- **Publisher:** PixiJS
- **License:** MIT
- **Source:** <https://github.com/pixijs/pixijs-skills/tree/main/skills/pixijs-scene-gif>

## Install

```bash

npx skills add https://github.com/pixijs/pixijs-skills --skill pixijs-scene-gif -a claude-code
```
