## Install

```bash
# Claude Code
git clone https://github.com/arjun988/blender-skills.git && cp -r blender-skills/.claude/skills /path/to/your/project/.claude/skills/

# Codex
git clone https://github.com/arjun988/blender-skills.git && cp -r blender-skills/.claude/skills/* /path/to/codex/skills/

# Cursor
git clone https://github.com/arjun988/blender-skills.git
Copy-Item -Recurse -Force "blender-skills\.claude\skills\*" ".cursor\skills\"
```
