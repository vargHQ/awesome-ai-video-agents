# Roblox Studio MCP Server

The MCP server built into Roblox Studio: agents edit scripts, run Luau, generate meshes and playtest your game.

- **Type:** Guides · 3d Scenes
- **Status:** live
- **Publisher:** Roblox
- **License:** proprietary
- **Source:** <https://create.roblox.com/docs/studio/mcp>
- **Works in:** Claude Code, Codex, Cursor, Gemini CLI, mcp
- **Tags:** `roblox` `mcp` `luau` `games` `playtest` `game-engine` `official`
- **Full card, kept current:** <https://varg.ai/how-to/skills/roblox-studio-mcp.md>

## Install

```bash
# Claude Code
Roblox Studio: Assistant → … → Manage MCP Servers → turn on Enable Studio as MCP server → Quick connect → Claude Code

# Codex
Roblox Studio: Assistant → … → Manage MCP Servers → turn on Enable Studio as MCP server → Quick connect → Codex CLI

# Cursor
Roblox Studio: Assistant → … → Manage MCP Servers → turn on Enable Studio as MCP server → Quick connect → Cursor

# Gemini CLI
Roblox Studio: Assistant → … → Manage MCP Servers → turn on Enable Studio as MCP server → Quick connect → Gemini CLI

# mcp
/Applications/RobloxStudio.app/Contents/MacOS/StudioMCP
```
