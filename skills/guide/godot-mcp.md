# Godot MCP by Solomon Elias

MCP server for Godot: launch the editor, run projects, read debug output, and create scenes and nodes.

- **Type:** Guides · 3d Scenes
- **Status:** beta
- **Publisher:** Solomon Elias
- **License:** MIT
- **Source:** <https://github.com/Coding-Solo/godot-mcp>
- **Works in:** Claude Code, Cursor, mcp
- **Tags:** `godot` `mcp` `game-engine` `gdscript` `games` `debug`
- **Full card, kept current:** <https://varg.ai/how-to/skills/godot-mcp.md>

## Install

```bash
# Claude Code
claude mcp add godot -- npx @coding-solo/godot-mcp

# Cursor
Cursor Settings → Features → MCP → + Add New MCP Server → name godot, type command, command npx @coding-solo/godot-mcp

# mcp
npx @coding-solo/godot-mcp
```
