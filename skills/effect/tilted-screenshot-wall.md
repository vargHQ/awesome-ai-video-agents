# Tilted Screenshot Wall

A wall of screenshots seen at an isometric angle, columns scrolling up and down at different speeds.

- **Type:** Effects · Galleries
- **Status:** live
- **Publisher:** Aceternity UI
- **License:** Aceternity License (free components)
- **Source:** <https://ui.aceternity.com/components/3d-marquee>
- **Works in:** Claude Code, claude-ai, Codex, Cursor, OpenClaw, Gemini CLI, mcp, varg Studio
- **Tags:** `gallery` `screenshots` `3D` `wall` `hyperframes` `remotion` `capcut`
- **Full card, kept current:** <https://varg.ai/how-to/skills/tilted-screenshot-wall.md>

## Install

```bash
# Claude Code
claude plugin marketplace add vargHQ/skills && claude plugin install varg@varg

npx skills add vargHQ/skills --skill varg-video-edit-library -a codex -y
```
