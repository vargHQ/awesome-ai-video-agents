## Install

```bash
# Claude Code
/plugin marketplace add higgsfield-ai/skills
/plugin install higgsfield@higgsfield

# Codex
npx skills add higgsfield-ai/skills --skill higgsfield-soul-id -a codex

# Cursor
npx skills add higgsfield-ai/skills --skill higgsfield-soul-id -a cursor

# Gemini CLI
npx skills add higgsfield-ai/skills --skill higgsfield-soul-id -a gemini-cli
```
