## Install

```bash

/plugin marketplace add higgsfield-ai/skills
/plugin install higgsfield@higgsfield

# Codex
npx skills add higgsfield-ai/skills --skill higgsfield-generate -a codex

# Cursor
npx skills add higgsfield-ai/skills --skill higgsfield-generate -a cursor
```
