## Install

```bash
# Claude Code
claude mcp add hf-mcp-server -t http https://huggingface.co/mcp?login

# Gemini CLI
gemini mcp add -t http huggingface https://huggingface.co/mcp?login

# mcp
https://huggingface.co/mcp
```
