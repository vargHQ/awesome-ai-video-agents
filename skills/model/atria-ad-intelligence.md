Official Atria plugin: search the ad library, tear down competitors, build swipe files, weekly account reports.

- **Full card, kept current:** <https://varg.ai/how-to/skills/atria-ad-intelligence.md>

## Install

```bash
# Claude Code
claude plugin marketplace add JoinScenius/atria-plugins && claude plugin install atria@atria

# Codex
codex plugin marketplace add JoinScenius/atria-plugins && codex plugin add atria@atria
```
